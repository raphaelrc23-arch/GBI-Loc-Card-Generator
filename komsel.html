Ketua Komsel boleh merangkap jadi anggota di komsel lain

Default: 1 jemaat hanya boleh terdaftar sebagai anggota di 1 komsel. Kalau diaktifkan, jemaat yang menjabat Ketua di sebuah grup tetap boleh ditambahkan sebagai anggota biasa di grup lain.

Zona Berbahaya

Hapus Semua Data Komsel

Menghapus SELURUH data grup, anggota, dan riwayat pertemuan/absensi secara permanen. Data Database Jemaat (di luar modul ini) tidak terpengaruh.

Impor Data dari File Excel (.xlsx)

Format Sheet yang Dikenali:

  • Daftar Grup: Nama Grup, Kategori, Wilayah, Leader, Hari, Waktu, Frekuensi, Maks Anggota
  • Daftar Anggota: Nama Grup, Nama Lengkap, NIJ, Tanggal Bergabung
  • Parameter: Allow Leader Multi, Default Max Anggota

Konfirmasi Hapus Semua Data

Semua data grup, anggota, dan pertemuan/absensi di modul Komsel akan dihapus permanen dan tidak bisa dikembalikan.
